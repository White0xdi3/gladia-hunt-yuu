## SUMMARY

**No REAL_SECRET findings.** All scanned hits are test fixtures, example values, or known API design patterns.

**Top anomaly to track:** The **callback URL SSRF vector** exists in both the Vercel AI SDK provider (`gladiaTranscriptionModelOptionsSchema.callbackConfig.url`) and the official Gladia JS/Python SDKs (`PreRecordedV2CallbackConfig.url`, `LiveV2CallbackConfig.url`). These accept arbitrary strings with no scheme/origin validation. The actual risk depends on **Gladia API behavior** (whether it fetches the callback URL server-side). RAG confirms this is a known, accepted SSRF-by-design surface (`SSRF@api.gladia.io`).

**Supply-chain note:** The unofficial npm package `gladia@0.1.3` remains a confusion vector but is not actively malicious — it's an orphaned personal package.
